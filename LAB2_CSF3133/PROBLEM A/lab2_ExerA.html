About the Event

COMTECH Event 2026 is a technology event organised for students to explore computer technology, programming, web development and digital innovation.

Web Development Workshop

Participants will learn the basics of HTML and how to create a simple website using HTML elements.

Computer Technology Talk

This session introduces students to computer technology trends and career opportunities in the information technology industry.
